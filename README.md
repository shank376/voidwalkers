# VOIDWALKERS — Website

A responsive, single-page website for the Voidwalkers exploration community.

## Run locally
No build tools or package installation are required.

1. Extract the ZIP.
2. Open `index.html` in a modern browser.

For a local development server, you can also run:
- `python -m http.server 8000`
- Visit `http://localhost:8000`

## Included
- Cinematic homepage and responsive navigation
- Community introduction and philosophy
- Exploration categories
- How-it-works section
- Field archive placeholder
- Community principles
- Contact CTA
- Mobile navigation and scroll effects

## Notes
- The name is set to **VOIDWALKERS** throughout the site.
- Contact uses `hello@voidwalkers.community` as a placeholder email. Replace it with the official contact address before launch.
- The first version is frontend-only. It does not store membership applications or provide accounts, voting, or an admin dashboard.
- Photography and Google Fonts load from external services, so an internet connection is needed for those assets.
- Replace sample imagery and review all community text before public launch.
